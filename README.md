# Pulse Fitness Landing Page

A premium, high-performance landing page for a daily fitness tracking mobile app. Inspired by the design aesthetics of Apple and Nike.

## Features
- **Hero Section**: High-impact visuals with 3D app mockups.
- **Glassmorphism UI**: Modern, semi-transparent design elements.
- **Responsive Design**: Optimized for mobile, tablet, and desktop.
- **Lucide Icons**: Clean, scalable vector icons.
- **Smooth Animations**: CSS-driven transitions and JavaScript-powered interactions.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom design system with CSS variables.
- **JavaScript**: Interactive elements and scroll effects.
- **Lucide**: Icon library.

## Getting Started
Simply open `index.html` in your browser to view the landing page.
